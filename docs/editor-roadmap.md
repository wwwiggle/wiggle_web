# Wiggle 편집 기능과 Excalidraw 제한 도입 계획

## 결론

Excalidraw로 학생용 핵심 그림 캔버스를 교체하지 않는다. Wiggle의 수업 캔버스에는 단계 자동 저장, 질문 전후 버전, 점선·연필 시범 분리 레이어, 단계 진행, 타임랩스가 이미 연결되어 있다. Excalidraw 문서 모델로 바꾸면 이 연결을 다시 구현해야 하고, 저학년에게 불필요한 선택 도구와 화면 복잡도가 커진다.

Excalidraw는 다음 두 위치에서만 별도 편집기로 검토한다.

1. **교사용 참고 자료 편집기**
   - 교사가 참고 이미지 위에 글, 화살표, 원, 강조 표시를 배치한다.
   - 성인 화면이므로 선택·이동·크기 조절 UI를 사용할 수 있다.
   - 학생에게는 편집기가 아니라 완성된 읽기 전용 참고 자료만 전송한다.
2. **완성 후 이야기·공유 카드 꾸미기**
   - 아이의 원본 그림은 잠긴 배경 이미지로 둔다.
   - 제목, 짧은 말풍선, 스티커, 사진 배치만 허용하는 Wiggle 전용 단순 도구막을 제공한다.
   - 원본 작품은 수정하지 않고 별도 구성 문서와 결과 이미지를 저장한다.

## 사용하지 않는 위치

- 선·도형 기초, 따라 그리기, 관찰 그리기, 자유 창작의 학생용 핵심 캔버스
- 점선·연필 시범과 점선 연습 레이어
- AI 질문 전후 버전과 타임랩스의 원본 선 기록
- 저학년에게 Excalidraw 전체 도구막을 노출하는 화면
- 완성 PNG에서 선을 자동으로 찾아 개별 객체로 되돌리는 기능

Excalidraw는 완성 이미지를 자동으로 편집 가능한 개별 선으로 되돌리는 도구가 아니다. 완성 그림을 불러올 때는 배경 이미지로 잠그고, 그 위에 새 요소를 추가하는 비파괴 편집만 제공한다.

## 핵심 캔버스 확장 방식

수업 중 필요한 기능은 현재 `DrawDocument`를 버전 호환 방식으로 직접 확장한다.

1. `text` 동작을 추가해 이름표, 제목과 말풍선을 작품·타임랩스·최종 이미지에 함께 저장한다.
2. 선택 가능한 도형·스티커·텍스트의 위치, 크기와 회전 정보를 추가한다.
3. 자유선은 기본적으로 아이의 원본 선으로 보존하고, 명시적으로 선택한 경우에만 이동을 허용한다.
4. 지우개·채우기·혼합 모드 레이어의 호환성을 마이그레이션 테스트로 고정한다.

### 현재 구현된 짧은 글씨 (2026-08-08)

- 이름표 12자, 제목 20자, 말풍선 30자(최대 두 줄), 작품당 활성 글씨 5개
- 글씨를 쓴 뒤 도화지에서 위치를 직접 선택하거나 `빈 곳 추천`을 명시적으로 요청
- 선택 테두리를 끌어 이동하고, 큰 버튼으로 내용·3단계 크기·색·삭제를 조정
- 수정 상태를 덮어쓰지 않고 같은 글씨 객체의 새 동작으로 저장해 되돌리기·타임랩스에 포함
- 일반 캔버스, 자동 저장, 썸네일, 최종 PNG, 가족용 타임랩스가 같은 렌더러를 사용
- 기기 키보드의 받아쓰기 마이크를 사용할 수 있도록 안내하되, 앱이 음성을 별도로 녹음·보관하지 않음
- 흰색·밝은 글씨에는 자동 대비 외곽선을 넣고, 글씨가 도화지 밖으로 나가지 않도록 안전 영역을 제한

`빈 곳 추천`은 현재 외부 AI 호출이 아니다. 문서의 선·도형·글씨가 적은 후보 위치를 계산하는 결정적 기능이다. 아이가 요청했을 때만 실행하며 결과를 직접 끌어 바꿀 수 있다. 실제 이미지 이해 기반 AI 배치는 교실 데이터, 비용, 지연, 개인정보 검증 전에는 자동 적용하지 않는다.

## 별도 구성 문서

완성 후 꾸미기에는 원본 그림 문서와 다른 `CompositionDocument`를 사용한다.

- 원본 작품 ID와 잠긴 배경 이미지 버전
- 텍스트, 말풍선, 스티커, 사진 이미지의 위치·크기·회전
- 편집기 장면 버전과 미리보기 이미지
- 생성한 사람과 생성·수정 시각

관계형 메타데이터는 D1, 장면 JSON과 결과 이미지는 R2에 저장한다. 가족 공유 링크는 원본 작품과 승인된 구성 결과를 명확히 구분한다.

## 성능·접근성 경계

- Excalidraw 코드는 별도 경로에서만 동적으로 불러온다.
- 학생 입장과 수업 캔버스 번들에는 포함하지 않는다.
- 작은 화면에서는 기능을 제목·말풍선·스티커·이동·크기 조절로 제한한다.
- 모든 기능은 그림 아이콘, 음성 안내와 44px 이상의 조작 영역을 함께 제공한다.
- 구형 iPad에서 첫 로딩, 메모리 사용량과 스타일러스 지연 기준을 통과한 뒤에만 학생 화면을 확장한다.

## 순차 개발

1. ✅ 교실 메시지·가족 공유·성장 기록의 모바일·저장 안정화
2. ✅ 핵심 캔버스에 짧은 글씨 입력과 저장·렌더링·타임랩스 추가
3. 🟡 글씨 선택·이동·크기·색 조절 완료. 스티커 붙이기와 도형·스티커 골라서 옮기기·지우기·크기 바꾸기는 2026-10-11 추가. 회전은 다음 단계
4. 교사용 참고 자료 편집기에서 Excalidraw를 작은 실험 기능으로 검증
5. 성능과 사용성 기준을 통과하면 완성 후 이야기·공유 카드 편집기로 확장
6. 실제 저학년과 교사 관찰 결과에 따라 학생의 편집 범위를 더 줄이거나 확대

각 단계는 이전 단계의 저장 호환성, 모바일 화면, 접근성, 권한 검증을 통과한 뒤 다음 단계로 진행한다.

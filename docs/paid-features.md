# 유료 요금제로 잠근 기능

2026-10-31 사용자 결정: "그림을 그리는 부분은 지금 웹사이트에서 안보여야해. 제거하지는 말고. 유료 요금제로 사용 못하게 클릭이 안되도록 막아둬. 마우스를 갖다대면 금지표시가 뜨게 만들면 돼."

- **켜고 끄는 곳**: `lib/feature-locks.ts`의 `DRAWING_LOCKED`. `true`면 잠기고 `false`면 예전처럼 열린다.
- **코드**: 지운 것이 없다.
- **잠긴 단추와 카드**: `PaidLock`(`app/components/PaidLock.tsx`)으로 보인다.
  - 회색으로 흐리게 보이고, 「🔒 유료 요금제」 표시가 붙는다.
  - 누를 수 없고, 마우스를 올리면 금지 표시(`cursor: not-allowed`)가 뜬다.

## 그림 그리기 — 무엇이었나

학생이 웹 그림판에서 직접 그림을 그리는 기능이다.

- **그림판**(`DrawingStudio`, `/student/draw/<id>`): 펜·붓·도형·스티커·스포이드·채우기·글자 도구, 되돌리기, 자동 저장, 완성 후 돌아보기.
- **몽그리 AI 코칭**(`/api/ai/coaching`): 아이가 부르거나 정해진 조건에서 질문을 건네는 AI 도우미.
- **선생님 실시간 그림 보기**:
  - 수업실 「오늘 수업」의 학생 그림 칸, 미리보기 창의 실시간 그림, 선생님 표시(그림 위에 그리는 지도 표시).
  - AI 코칭 초안(`/api/ai/teacher-draft`).
- 손들기와 선생님 메시지 받기는 그림판 안에만 있다. 그래서 잠긴 동안에는 학생에게 보이지 않는다.

## 어디가 어떻게 잠기나

| 곳 | 잠긴 모습 |
|---|---|
| 학생 「그림 자리」의 **내 그림 칸 전체**: 새 그림 그리기, 그리는 중·완성 그림 카드, 「내 그림 모두 보기」 | 잠금 카드·잠금 글자(누를 수 없음, 2026-11-01 사용자 지시) |
| `/student/archive`(내 그림 보관함), `/student/archive/<id>`(완성 그림 보기) | 잠금 안내 화면 |
| 보관함·완성 그림 상세 안의 「이어 그리기」·「새 그림으로 다시 그리기」 | 잠금 단추(잠금을 풀었을 때를 위해 남겨 둠) |
| 처음 들어온 학생(그림·그림책 0개) | 빈 도화지로 보내지 않고 「그림 자리」를 연다 |
| `/student/draw/*` 주소로 바로 들어오기 | 잠금 안내 화면. 내 그림책과 처음 화면으로 가는 단추가 있다 |
| 선생님 「오늘 수업」 학생 그림 칸 | 잠금 칸(실시간 보기 안 열림) |
| API: `POST /api/artworks`, `PUT /api/artworks/[id]`, `PUT /api/artworks/[id]/image`, `POST /api/ai/coaching`, `POST /api/ai/teacher-draft` | `403 { code: "DRAWING_LOCKED" }`. 409가 아니므로 기기에 남은 저장분은 지우지 않고 보존한다 |

## 그대로 쓰는 것

- 그림 읽기 API(`GET /api/artworks*`). 이미 그림책에 넣은 그림이 계속 보이도록 남겨 둔다.
- 그림책 만들기 전부: 새 그림(파일·끌어다 놓기), 배경, 붙여넣기(Ctrl+V), 패턴 면지.
- 그림책 편집기의 「🎨 내 그림」 가져오기 단추는 2026-11-01에 편집기에서 뺐다(코드의 읽기 API는 남아 있다).
- 가족 공유의 타임랩스.
